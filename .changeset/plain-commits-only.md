Add the `no-tool-credit` rule, on in every config. It rejects a commit message with a co-author trailer that names a coding tool or its vendor, a tool session trailer, a line that opens with `Generated with` or `Generated by`, or a tool session link. It reuses the pattern list from `@cteic/pr-clean`, which is now a dependency.
